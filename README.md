# 网易云扫码登录

羽化面板插件。用户私聊机器人发送 `网易云登录`，用网易云音乐 App 扫码并确认，插件会将账号的 `MUSIC_U` 写入青龙的 `NETEASE_MUSIC_U` 环境变量。二维码和凭证不在群聊发送，凭证不会被回复给用户。

## 管理员配置

1. 在羽化面板的依赖管理中安装 Node.js 依赖 `qrcode`。
2. 在青龙开放平台创建应用，授予环境变量的查看、新增和修改权限。
3. 安装插件，在插件设置的“青龙连接”中填写 `青龙地址丨Client ID丨Client Secret`，分隔符是中文 `丨`。地址需从羽化面板容器内可访问；例如同一 Docker 网络可使用 `http://qinglong:5700`。
4. 启用插件后，用户私聊发送 `网易云登录`，在三分钟内用网易云音乐 App 扫码并确认。

插件按网易云账号 UID 区分变量。同一账号重新扫码会更新对应变量；不同账号各新增一条同名变量，原有无 UID 标记的变量不会覆盖。若已有账号的旧变量未带标记，首次扫码会新增一条，请管理员核对后自行整理。

**任务兼容性：**插件只负责登录和保存凭证。多个同名变量能否被任务逐个处理取决于具体脚本及青龙任务设置；现有的 `netease_combined.js` 一次只读取一个 `NETEASE_MUSIC_U`，不能仅凭添加多条变量就保证逐账号运行。请为不同账号配置独立任务与对应变量，或修改任务脚本支持多账号。

插件使用网易云未公开的扫码接口，接口或风控变化可能导致登录失败。
