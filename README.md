# 网易云扫码登录

羽化面板插件。用户通过私聊管理网易云账号，登录凭证保存到青龙环境变量 `NETEASE_MUSIC_U`，不会回复到聊天中。

- `网易云登录`：选择 `1` 扫码、`2` 手机号验证码或 `3` Cookie 登录。菜单等待 60 秒，手机号、验证码和 Cookie 每步等待 2 分钟，扫码等待最多 3 分钟；各步骤发送 `q` 可退出，超时也会退出。
- `网易云手机登录` 和 `网易云Cookie登录`：仍可直接进入相应流程。

三种登录方式都会验证账号并绑定当前聊天平台及用户。手机号、验证码和 Cookie 不会被插件回复，插件通过中间件请求撤回输入消息；实际能否撤回取决于聊天平台，请勿在群聊中发送。

- `网易云查询`：直接查询网易云接口，显示等级、云贝余额、今日云贝增加、会员成长值今日增加、签到及音乐人任务状态。今日增量通过网易云收入明细按北京时间汇总；如明细未覆盖完整当天，会标为“至少”。这些是账号状态，不是脚本执行日志。
- `网易云删除`：选择账号，再回复“确认删除”，删除对应青龙环境变量和绑定；回复其他内容或超时则取消。通过 NCMM 登录的账号仍保存在 NCMM，需管理员单独处理。

不同聊天平台的账号分别绑定；同一网易云账号不能同时绑定不同聊天用户。如需转移绑定，请先由原用户删除，或联系管理员处理。青龙变量备注中记录网易云 UID、平台及用户 ID，用于识别归属。

## 管理员配置

1. 在羽化面板的依赖管理中安装 Node.js 依赖 `qrcode`。
2. 在青龙开放平台创建应用，授予环境变量和脚本模块权限，用于读写变量和读取 NCMM 账号文件。青龙的脚本模块权限同时包含写入能力，请使用专门的应用凭据。
3. 安装插件，在插件设置的“青龙连接”中填写 `青龙地址丨Client ID丨Client Secret`，分隔符是中文 `丨`。地址需从羽化面板容器内可访问；例如同一 Docker 网络可使用 `http://qinglong:5700`。
4. 若使用手机验证码登录，在插件设置中填写 NCMM Web 地址、管理员密码和 NCMM 工作目录相对于青龙 scripts 的路径。你当前的目录为 `3899_ncmm_main/scripts`。
5. 启用插件后，用户在私聊中发送上述指令。

同一账号再次扫码会更新对应变量。旧版插件创建了 UID 标记但没有用户绑定的变量，需由账号持有人重新扫码认领；没有 UID 标记的旧变量不会自动覆盖或认领。若存在同一 UID 的多条记录，请管理员先核对整理。

**任务兼容性：**插件只负责登录和保存凭证。多个同名变量能否被任务逐个处理取决于具体脚本及青龙任务设置；现有的 `netease_combined.js` 一次只读取一个 `NETEASE_MUSIC_U`，不能仅凭添加多条变量就保证逐账号运行。请为不同账号配置独立任务与对应变量，或修改任务脚本支持多账号。

插件使用网易云未公开的登录接口；短信发送、验证码登录和扫码可能受到接口变化或风控影响。

手机验证码由 NCMM 发送和验证；NCMM 会将账号保存为辅助账号并加入任务配置，再同步凭证到青龙变量。请勿在群聊中发送个人信息。

NCMM 可能要求额外验证或拒绝请求；请以实际登录结果为准。同步失败时，NCMM 可能已经保存账号，请先在 NCMM 检查，避免重复登录。

## 简洁功能菜单

安装 `简洁功能菜单` 后，发送 `菜单`：一级直接展示所有插件，回复编号查看该插件的简介和指令；发送 `q` 退出，60 秒无操作自动退出。查看二级菜单后会话结束，可直接发送指令；再次发送 `菜单` 返回一级菜单。菜单按插件的管理员标记过滤，并在能够读取插件头部的平台标记时过滤不支持的平台。复杂正则或自动监听规则可能无法列出；具体权限仍由各插件决定。默认读取羽化容器内的 `http://127.0.0.1:6060`，端口不同时可在插件设置中修改内部地址。

菜单插件配置页直接显示自动抓取的各插件项目，每项可设置显示开关、名称、简介、指令和顺序。配置页还提供三个自定义项目；如需更多，可修改“自定义项目数量”（最多 20），保存后发送一次 `菜单`，重新打开配置页即可看到新增项目。自定义项目需要开启开关并填写名称与指令。每次发送 `菜单` 都会刷新项目配置；新安装的插件可能需要发送一次 `菜单` 并重新打开配置页后才出现。

更改菜单中的指令只改变显示文字，不会改变插件的实际触发规则。保留原有设置作为迁移来源，旧格式项不再出现在配置界面。

菜单设置按基本设置、自动项目和自定义项目分组展示，各项目的显示、名称、简介、指令和排序集中在对应标题下。
